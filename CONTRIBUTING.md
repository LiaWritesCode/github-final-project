## Introduction to github-final-project
All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.  
Please note we have a **[Code of Conduct](https://github.com/LiaWritesCode/github-final-project/blob/main/CODE_OF_CONDUCT.md)**, please follow it in all your interactions with the project and its community.

## Pull Request Process
1. Fork the repository.
2. Commit your changes to the fork.
3. Submit a pull request and be sure to add yourself to the author file.
4. Handle any feedback before your request is merged.
5. Remember that you are awesome and please take our sincerest gratitude!
