All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.  
Please note we have a **[Code of Conduct](https://github.com/LiaWritesCode/github-final-project/blob/main/CODE_OF_CONDUCT.md)**, please follow it in all your interactions with the project and its community.

## Pull Request Process
    1. Fork the repository.
    2. Commit your changes to your fork.
    3. Submit a pull request. Don't forget to add yourself in the Authors file!
    4. Handle any feedback before the request is merged.
    5. Remember you are awesome and take our sincerest gratitude!
